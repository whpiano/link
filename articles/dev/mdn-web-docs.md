# MDN Web Docs

- **原链接：** <https://developer.mozilla.org/zh-CN/>
- **分类：** 开发编程
- **标签：** `文档` `前端` `HTML/CSS/JS`
- **收录日期：** 2026-11-05

## 这是什么

MDN Web Docs 是由 Mozilla 维护、社区共同贡献的 Web 技术文档站，自 2005 年起持续记录 HTML、CSS、JavaScript 和各类 Web API，被广泛视为前端开发最权威、最常用的参考资料之一。这个链接是它的简体中文入口，内容依据知识共享许可协议提供。

## 主要功能 / 要点

- **参考文档**：HTML 元素与属性、CSS 属性与选择器、JavaScript 内置对象与语法、Web API（Fetch、Service Worker、Geolocation 等）
- **学习路径**：「学习 Web 开发」模块，从零开始讲 HTML、CSS、JavaScript
- **浏览器兼容性数据**：每个特性页面通常附有各浏览器支持情况表
- **在线工具**：Playground、HTTP Observatory（网站安全检测）、Border-radius / Box-shadow 生成器、颜色转换等
- **MDN MCP 服务器**：官方博客介绍可把 MDN 文档和兼容性数据接入编辑器或 AI 编程助手
- 部分页面已有中文翻译，未翻译的会显示英文原文

## 适合谁

- 前端 / 全栈开发者日常查阅 API 和语法
- 正在学习网页开发的初学者
- 需要确认某个特性浏览器兼容性的工程师

## 怎么用

1. 直接用站内搜索，或在搜索引擎里加上「mdn」关键词（如「mdn flex」）。
2. 初学者可从「学习 Web 开发」板块按模块顺序学习。
3. 中文页面有时落后于英文版，遇到内容存疑可切换到英文原文对照。

## 注意事项

- 免费使用，无需登录；有可选的付费订阅 MDN Plus 和广告位。
- 官方站点，无明显安全或隐私风险。
- 中文翻译由社区维护，个别页面可能过时或未翻译。
