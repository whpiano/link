- **标签：** `代码` `开源` `Git` `协作`
- **收录日期：** 2026-11-05

## 这是什么

GitHub 是全球最大的代码托管与开源协作平台，基于 Git 版本控制系统，2018 年被微软收购。开发者在这里存放代码、协作开发、发布开源项目；绝大多数知名开源软件都托管在 GitHub 上。本导航站收录的很多工具本身就是 GitHub 上的开源仓库。

## 主要功能 / 要点

- 代码仓库托管：公开或私有仓库，完整的版本历史
- 协作功能：Issues（问题跟踪）、Pull Request（代码审查与合并）、Discussions、Wiki
- GitHub Actions：持续集成 / 自动化流程
- GitHub Pages：免费托管静态网站
- Releases：发布软件安装包，很多开源工具在这里提供下载
- Copilot：AI 编程助手；Codespaces：云端开发环境
- Gist：分享代码片段和笔记（如本站收录的提示词模板）

## 适合谁

程序员和开发团队；想下载开源软件、查看项目说明的普通用户；想托管个人网站或笔记的人。

## 怎么用

1. 不登录也能浏览公开仓库、阅读 README、下载 Releases
2. 注册免费账号后可以 Star 收藏、Fork 复制项目、提交 Issue
3. 安装 Git 或 GitHub Desktop，把自己的代码推送到仓库

## 注意事项

- 基础功能免费；Copilot、高级安全等功能需付费，Actions、Codespaces 有免费额度
- GitHub 上的项目由第三方发布，下载运行前要看清来源、Star 数和代码内容，警惕伪装成热门项目的恶意仓库
- 不要把密码、API Key 等敏感信息提交到公开仓库
- 国内访问速度可能不稳定
