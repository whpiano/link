- **标签：** `AI 编程` `编程助手` `免费` `Codebuff` `CLI`
- **收录日期：** 2026-11-10

## 这是什么

Freebuff 是一个主打“100% 免费、不限量”的 AI 编程智能体（coding agent），官网标语是“$0 forever, unlimited usage”。它不靠订阅收费，而是用**广告**来支付模型调用成本，无需绑卡、也不用盯着额度。页脚链接到开源项目 CodebuffAI/codebuff，可以理解为 Codebuff 团队推出的免费版本。

## 主要功能 / 要点

- **免费使用前沿模型**：界面示例中默认模型为 Claude Haiku 5.5，由广告收入支撑。
- **能真正动手干活**：读文件、改代码、跑测试命令，示例里能定位并修复偶发失败的测试。
- **多端同步**：线程保存在云端，桌面端（macOS / Windows / Linux）、手机端（iOS / Android）、终端 CLI、浏览器网页版之间可以接着用。
- **一键集成**：可连接 GitHub、Linear、Notion、Stripe、Vercel、Supabase、Sentry 等，智能体在工作中直接调用。
- **其他产品线**：网站构建器（Website Builder）、Cowork、学生计划等。

## 适合谁

- 想体验 AI 编程智能体、但不想付 Cursor / Claude Code 等订阅费的开发者和学生。
- 做个人项目、小工具、原型，对广告不太介意的人。

## 怎么用

1. 打开官网，网页版可直接在浏览器使用；也可下载桌面端或手机端。
2. 终端用户可通过官网给出的 npm 包安装 CLI，在项目目录里运行。
3. 登录后新建对话或项目，用自然语言描述任务，让它读代码、改代码、跑命令。

## 注意事项

- **广告换免费**：免费来自广告投放，使用时会看到广告，且可能涉及使用数据用于广告，请先读其隐私政策。
- **需要登录**：云端同步线程需注册账号。
- **代码与授权安全**：智能体会读取你的代码并可执行命令；连接 GitHub、Stripe 等第三方账号时只授予必要权限，不要在敏感/公司代码库上随意使用。
- “免费不限量”属于官方宣传，实际可能有会话额度（界面里有“Session remaining”提示），以实际使用为准。
