# LinkAndroid

- **原链接：** https://linkandroid.com/
- **分类：** AI 工具
- **标签：** `安卓控制` `投屏` `ADB` `自动化`
- **收录日期：** 2026-11-05

## 这是什么

一款"全能 Android 手机连接助手"桌面软件，由 ModStart 团队开发（GitHub：modstart-lib/linkandroid），核心功能以 Apache-2.0 协议开源。通过 USB 或无线方式把安卓手机连到电脑上，集投屏、文件管理、应用管理、ADB 终端、自动化脚本和 AI 大模型于一体。

## 主要功能 / 要点

- 投屏与操控：基于定制 scrcpy 引擎的低延迟镜像，键鼠反向控制手机，支持多设备
- 文件管理：浏览手机文件系统，拖拽上传下载、批量操作
- 应用管理：查看已装应用，一键安装 APK、批量卸载、从电脑启动应用
- 内置 ADB Shell 终端和常用命令面板
- 自动化脚本（Pro）：基于 uiautomator2 的 Python 脚本引擎，支持 Cron 定时任务
- AI 集成：支持 OpenAI、Anthropic、Google、DeepSeek 等 40+ 提供商及本地 Ollama / LM Studio，可用 AI 辅助写脚本

## 适合谁

需要同时调试多台手机的 Android 开发、测试人员；想在电脑上操作手机、录屏截图的评测博主；希望做手机自动化的用户。

## 怎么用

在官网"软件下载"页下载对应系统版本（Windows、macOS，Linux 开发中），手机开启 USB 调试后用数据线连接，或通过扫码 / 配对码 / IP:端口无线连接。

## 注意事项

- 核心功能免费；多设备协同、设备分组、自动化脚本等属 Pro 功能，需付费订阅
- 需开启手机 USB 调试 / ADB 权限，等于赋予电脑较高控制权限，只在可信电脑上使用，用完建议关闭
- 接入云端大模型时需填写自己的 API Key，相关数据会发给对应服务商
- 建议从官网或官方 GitHub 下载，避免第三方修改版
