## 这是什么

LightVela 是腾讯轻量云出品的云端 AI 智能体服务，核心是托管在云端、7×24 小时在线的 Hermes Agent。它可以接入微信、QQ、企业微信、飞书、钉钉、Telegram、Discord、Slack、WhatsApp 等聊天渠道，在群聊或私聊里帮你整理信息、跑定时任务、做网页。官网写明新用户免费体验 1 个月，送 4500 AI 积分（原导航简介为“现在 0 元会员 4500 积分”）。

## 主要功能 / 要点

- 多平台聊天接入，可同时连接多个渠道
- 定时任务与条件提醒：行情晨报、降价监控、喝水吃药等模板，通知类与脚本类任务不消耗 Token
- 长期记忆与个性化，把你的反馈沉淀成规则
- 工作台：用一句话生成并发布可分享的网页（个人主页、看板、活动页）
- 可安装技能扩展；Labs 提供一键部署 DeepSeek Harness 的云端环境
- 涉及发送、删除、修改等外部动作会先请求确认

## 适合谁

想要一个常驻聊天软件里的 AI 助理、又不想自己折腾服务器部署 Agent 的个人用户、小团队和店主。

## 怎么用

1. 打开官网点“免费试用”，注册并开通体验
2. 创建助理：起名字、选模型，等状态显示 Running
3. 在「通道」里按文档指引连接微信、QQ、飞书等
4. 直接在聊天里用自然语言交代任务

## 注意事项

- 需要注册账号；免费体验 1 个月和 4500 积分属于新用户活动，到期后需付费，活动随时可能调整
- 把 Agent 接入微信、企业群等渠道意味着它能读到相关聊天内容，注意群成员隐私和公司数据合规
- 授权它代发消息、操作外部服务前，确认权限范围；不要让它处理银行卡、证件等敏感信息
- 官网展示的用户评价与案例为宣传内容
