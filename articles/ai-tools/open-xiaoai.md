# open-xiaoai（小七）

- **原链接：** https://github.com/OwnDing/open-xiaoai
- **分类：** AI 工具
- **标签：** `小爱` `ai` `智能家居` `Home Assistant`
- **收录日期：** 2026-11-05

## 这是什么

OwnDing 维护的开源项目，Fork 自已归档的 idootop/open-xiaoai，MIT 协议。它接管小爱音箱的"耳朵和嘴巴"，接入小智服务端、Hermes Agent（底层模型为 DeepSeek）和 Home Assistant，把音箱变成名为"小七"的 AI 家庭管家。作者自述在自家真实环境中每天使用、持续更新。

## 主要功能 / 要点

- 连续对话、随时打断，说"拜拜"即结束；会变的信息（天气、新闻）先联网查证
- 通过 Home Assistant 控制米家、海尔等多品牌设备，并查询设备实时状态
- 语音创建定时任务、场景和联动（如"洗衣机洗完提醒我"、漏水报警），保存前会复述确认
- 主动播报，跟随小爱的勿扰时段，安全类报警例外
- 离线播放家里电脑上的本地曲库；可选控制安卓电视（目前在 TCL 雷鸟上验收）
- 不刷机方案：普通蓝牙 / USB 音箱接到常开电脑上也能用
- 安全边界：门锁、燃气等高风险设备不允许放进场景或联动

## 适合谁

有一定动手能力、已在用或愿意部署 Home Assistant 的智能家居玩家，以及想给小爱音箱接入大模型的折腾爱好者。

## 怎么用

按 README 的"快速开始"：刷机路线需先给音箱刷补丁固件并安装 Client，再部署小爱桥接、小智服务端、Home Assistant 和 Hermes；不刷机路线则在电脑上部署服务端并运行语音终端。各步骤都有单独文档。

## 注意事项

- 刷机教程**仅适用于小爱音箱 Pro（LX06）和 Xiaomi 智能音箱 Pro（OH2P）**，其他型号勿直接使用；刷机有变砖和失去保修的风险
- 非小米官方项目，README 声明仅供学术研究或个人测试，权利方主张权益时应停止使用
- 需要自备常开电脑 / 服务器，并使用大模型 API（可能产生费用）；家中语音会被持续监听处理，注意隐私
- 部署涉及多个组件，门槛较高
