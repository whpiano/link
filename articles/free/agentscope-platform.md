## 这是什么

AgentScope Platform 是 AgentScope 开源智能体生态的云端体验与社区平台。官网介绍：可以直接在浏览器里部署和运行用 AgentScope、QwenPaw 构建的智能体应用，发现新能力并与他人分享。目前处于 Beta 阶段，注册即可获得免费试用空间。原导航站把它概括为“免费服务器、免费 agent”。

## 主要功能 / 要点

- 一键部署 QwenPaw：注册后获得隔离的工作空间
- 记忆、技能（Skills）、MCP 配置会被保存，重新部署时自动恢复之前状态
- 首次成功部署 QwenPaw 可获得 200 Credits（以官网当前说明为准）
- 技能市场：浏览可复用技能并一键安装到自己的 QwenPaw
- 插件市场：发现、安装、发布插件，扩展模型、命令、页面和工具能力
- AgentDev Hub 社区：分享自己的配置、看社区优质方案

## 适合谁

想零成本体验在线 AI Agent、不想自己买服务器折腾部署的用户；对 AgentScope / QwenPaw 生态感兴趣的开发者。

## 怎么用

1. 打开官网，点击“Free Register”免费注册
2. 进入 Deploy 页面，一键部署 QwenPaw
3. 在技能市场 / 插件市场中挑选能力安装到自己的工作空间
4. 通过浏览器直接使用部署好的 Agent

## 注意事项

- 需要注册登录；目前是 Beta 免费试用，Credits 额度和免费政策随时可能调整或取消
- 这里的“免费服务器”指平台提供的 Agent 托管工作空间，并不是可随意使用的通用 VPS
- 连接 GitHub 等 MCP 服务时会授予第三方访问权限，注意只授予必要权限，不要存放敏感密钥和隐私数据
- 使用前请阅读平台的服务条款、隐私政策和使用政策
