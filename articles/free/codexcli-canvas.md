# 画布（天才程序员中转站）

- **原链接：** <https://codexcli.club/canvas>
- **分类：** 免费资源
- **标签：** `白嫖` `生图` `中转站`
- **收录日期：** 2026-11-05

## 这是什么

这是“天才程序员中转站”（codexcli.club）的 Canvas 画布页。codexcli.club 本身是一个第三方 API 中转站，宣称提供与官方兼容的 Claude、GPT 接口，按 Token 计费、无月费，并通过多上游账号轮询分流。画布是它的在线生图界面，可以输入提示词生成图片、上传图片做二次编辑。原导航站简介称“每天 50 张 gpt-image-2 额度”。

## 主要功能 / 要点

- 在线输入提示词生成图片，支持上传参考图、“润色”提示词
- 生成记录区分“Free / Paid”，失败时提示“上游繁忙，未扣费”
- 未登录时为演示模式，生成、上传、润色功能都需登录
- 同站还提供 API Key 用量查询（key-usage）、兼容 Claude Code / Codex CLI / Cherry Studio 等工具的接口

## 适合谁

想低成本试用 GPT 图像模型、能接受第三方中转服务风险的用户。

## 怎么用

1. 打开 codexcli.club 注册账号并登录
2. 进入 Canvas 页，输入提示词或上传图片后点击生成
3. 在生成记录中查看结果和是否计费

## 注意事项

- 需要注册登录；“每天 50 张 gpt-image-2 免费额度”来自原导航简介，页面上未看到明确说明，未能核实，免费额度可能随时取消
- 这是非官方的第三方中转站：你的提示词、上传图片都会经过该站服务器，存在隐私泄露风险，不要上传人脸、证件等敏感图片
- 中转站通常依靠多账号池转发官方接口，可能违反上游服务条款，存在随时跑路、封号、服务中断的风险，不建议大额充值
- 联系方式仅为 QQ 号，缺少公开的公司主体信息
