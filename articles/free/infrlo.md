# Infrlo

- **原链接：** <https://www.infrlo.com/>
- **分类：** 免费资源
- **标签：** `部署` `云托管` `免费套餐`
- **收录日期：** 2026-11-05

## 这是什么

Infrlo 是一个面向开发者的云托管（PaaS）平台，主打“git push 即部署”。官网宣称提供全球边缘网络、DDoS 防护、自动 HTTPS，并有无需信用卡的免费套餐。社区在 Discord 和 Telegram。

## 主要功能 / 要点

- 一次 git push 自动构建、容器化、路由和分发，宣称几秒内上线
- 支持 Node.js、Python、Go、Rust、Docker、Deno、Bun、Ruby、PHP、Java、Elixir、Kotlin 等
- 自动 HTTPS/SSL、零停机滚动部署、分支预览 URL、一键回滚
- 每档套餐都含 DDoS 防护，提供实时日志和资源用量面板
- 免费套餐无需信用卡

## 适合谁

想免费部署个人项目、小型 API、Bot 或练手应用的开发者。

## 怎么用

1. 打开官网点“Deploy for free”，进入 dash.infrlo.com 注册
2. 连接代码仓库或上传项目，按提示配置运行环境
3. 推送代码后等待自动构建上线，在面板查看日志与状态

## 注意事项

- 需要注册账号；免费套餐的具体资源限制（内存、休眠、流量等）官网首页未写明，以控制台为准
- 这是一个较新的小平台，官网的性能数字（2Gbps+、<50ms、99.9% 在线）为自述，未经独立验证
- 免费额度可能随时调整或取消，重要业务不要只依赖它，记得自行备份代码和数据
- 不要把敏感密钥硬编码进仓库，使用平台的环境变量功能
