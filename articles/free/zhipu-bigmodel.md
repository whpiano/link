## 这是什么

这是智谱 AI 大模型开放平台 BigModel（bigmodel.cn，北京智谱华章科技股份有限公司）的邀请注册链接。平台提供 GLM 系列大模型的 API 调用。注册页写明「新用户免费赠送专享 2000 万 tokens 体验包」。

## 主要功能 / 要点

- 通过 API 调用智谱 GLM 系列语言、视觉、图像等模型，有详细的官方 API 文档
- 新用户注册赠送 2000 万 Tokens 体验包
- 另有长期免费的 Flash 系列模型可调用，以及付费资源包、GLM Coding Plan 编程套餐等

**额度的实际构成**：据多篇网友实测文章，这 2000 万 Tokens 并非全部通用，而是拆成几个资源包，例如 200 万通用 Tokens + 若干只能用于指定模型（如 GLM-4.5-Air、GLM-4.6V）的额度；有效期多为注册起 3 个月。具体以登录后「财务 → 资源包」页面为准。

## 适合谁

- 想体验国产 GLM 大模型、做原型或学习 API 调用的开发者
- 需要一笔免费额度做测试的个人用户

## 怎么用

1. 打开链接，用手机号或微信扫码注册登录。
2. 在控制台「财务 → 资源包」查看到账额度和到期时间。
3. 在「API Key」页面创建密钥，按官方文档调用模型。

## 注意事项

- **这是带邀请码的推广链接**（url 含 icode=），邀请人可能因此获得奖励；介意可直接访问 bigmodel.cn 注册，新用户礼包通常同样可领。
- 需要手机号注册，部分邀请奖励要求实名认证。
- 宣传的「2000 万」大部分限定模型、有有效期，通用额度较少；免费额度和活动规则可能随时调整。
- API Key 等同于付费凭证，不要泄露或上传到公开仓库。
