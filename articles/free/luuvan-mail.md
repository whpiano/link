- **收录日期：** 2026-11-05

## 这是什么

一个越南语界面的免费临时邮箱（一次性邮箱）服务，站点自称 100% 运行在 Cloudflare Workers 与 D1 数据库上。不注册即可生成邮箱地址，用来接收注册验证邮件和 OTP 验证码。

## 主要功能 / 要点

- 一键生成邮箱，可随机或自定义前缀，提供多个可选域名
- 每个邮箱附带 Recovery Key（RK-xxxx），换设备或关掉浏览器后可凭它重新打开收件箱
- 可设置存活时间：5 分钟、15 分钟、1 小时到 24 小时，过期自动删除
- 访客每天最多创建 5 个邮箱；注册免费账号后可无限创建、永久保存，并获得 REST API Key
- 提供 REST API，可接入脚本、Telegram 机器人或自动化测试流程

## 适合谁

需要临时注册某些网站、试用服务又不想暴露真实邮箱的人；做邮件流程测试的开发者 / QA。

## 怎么用

打开首页点"Tạo Email"（创建邮箱）生成地址，记下 Recovery Key，把地址填到需要验证的网站，回到收件箱查看邮件即可。也可以在首页直接输入完整地址查看收件箱。

## 注意事项

- **这是临时邮箱服务**：首页支持"输入任意邮箱地址即可查看收件箱"，意味着知道地址的人可能看到同一收件箱的邮件，**切勿用于重要账号、找回密码或接收敏感信息**
- 临时邮箱域名常被网站屏蔽；邮箱过期后账号将无法找回
- 站点宣称"不记录 IP、零日志"等属自述，无法核实；为个人运营的免费服务，可能随时关停或改变规则
- 界面为越南语，可借助浏览器翻译
