## 这是什么

Free.ai 是一个把聊天、搜索、绘图、视频、语音、音乐、写作、代码等数百个 AI 工具聚合在一起的网站，运营方署名 Muddy Holdings LLC。主打“免费”：不注册每天 6,000 token，用邮箱注册后每天 30,000 token，每 24 小时重置。免费额度主要使用其自建 GPU 上的开源模型，GPT、Claude、Gemini 等高级模型需要付费余额。

## 主要功能 / 要点

- 官网称有 477+ 个 AI 工具、573 个模型，覆盖聊天、搜索、图片、视频、配音、转录、翻译、PDF 等
- 免费模型包括 Qwen 3.6 35B（聊天）、FLUX（绘图）、CogVideoX（视频）、Kokoro（语音合成）、Whisper（转录）等开源模型
- 视频是免费账户唯一单独限量的功能：每 2 天 1 段
- 提供兼容 OpenAI 格式的 REST API，注册后可获取 API Key
- 付费档位：Basic $5/月、Pro $19/月、Business $49/月；另有托管和浏览器 IDE（Coder）等付费服务
- 官网称生成内容可商用

## 适合谁

想免费试用多种 AI 工具、对模型要求不高的普通用户；需要少量免费 API 额度做测试的开发者。

## 怎么用

1. 打开链接按引导开始，不注册也能直接用（每天 6,000 token）
2. 输入邮箱注册并点击确认邮件，每天额度提升到 30,000 token
3. 在 Chat、Image、Video 等工具页直接使用，或到 API 页面生成 Key

## 注意事项

- 免费额度和政策随时可能调整或取消，原导航站所写数字以官网当前说明为准
- 免费额度主要对应开源模型，选用 GPT、Claude 等高级模型会扣付费余额
- 官网称不会永久存储、出售或用于训练用户数据，但仍不建议上传隐私或敏感文件
- 页面有推荐返利（referral）机制，注意分辨他人分享的推广链接
