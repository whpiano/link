## 这是什么

DiPlay 是一个独立社区项目（基于 xcertplay，界面设计源自 DiAuto），以 APK 形式安装到安卓车机上，让 iPhone 通过 USB 或 Wi-Fi 在车机屏幕上使用 CarPlay（地图、音乐、通话）。写作时为公开预览版 0.2.22，源代码在 GitHub 公开。

## 主要功能 / 要点

- 支持有线 USB 与无线连接（车机热点、Wi-Fi Direct 或同一局域网）
- 需 Android 7.0 及以上；7.0–8.1 为新增支持，尚待实车验证
- 无需越狱、转接盒或账号
- 项目主要面向比亚迪（DiLink）车机，其他品牌不在支持范围

## 适合谁

开比亚迪等安卓车机、想用 iPhone CarPlay 又不想买转接盒的车主，且愿意自己折腾测试版软件。

## 怎么用

停车后在车机上下载并安装 APK（安装方式取决于车机），授予蓝牙、Wi-Fi/位置、麦克风权限；按官网说明开启车机热点并在设置里填写，或用 USB 数据线连接后点“Connect with USB”。详细步骤见项目的 INSTALL 文档。

## 注意事项

- 免费、无需账号；但属于未经 Apple 认证的预览版，官网自述其认证使用从公开固件中提取的实验性配件身份，无法保证未来持续可用
- 在车机上安装第三方 APK 可能影响车机稳定性或保修，官网建议在停车时测试，切勿驾驶中操作
- 只从官网/GitHub Releases 下载，并核对发布页的校验值，谨防二次打包的版本
- 与 Apple、比亚迪无隶属关系
