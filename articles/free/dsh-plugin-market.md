# DSH 插件市场

- **原链接：** <https://dshopen.org/zh/#plugins>
- **分类：** 免费资源
- **标签：** `插件` `DeepSeek Harness` `DSH`
- **收录日期：** 2026-11-05

## 这是什么

“开放插件市场”（dshopen.org）是 DeepSeek Harness（简称 DSH）的社区插件索引站。DSH 从 10 月 15 日起支持自定义插件市场，把本站的索引地址添加进 DSH 的「发现」页，就能在 DSH 里直接浏览、搜索和安装社区插件。它是独立社区项目，与 DeepSeek 官方无隶属关系，源码在 GitHub（polang233/dsh-plugin-index）。

## 主要功能 / 要点

- 收录 1000+ 个社区插件（截至 2026-11-04 为 1031 个），分为集成、工具、界面、技能、外观、开发与运维、工作流、模型供应商、用量与费用、记忆、知识与研究 11 类
- 默认推荐每 6 小时轮换，综合增长、更新频率、审查、下载量、star 和点赞，同一作者不霸榜
- 每个插件有详情页，标注版本、适用 DSH 版本、源码与 npm 链接，部分带“已审查”标签
- 支持按点赞、星数、近期增长、最近更新、随机排序
- 可在 GitHub 提交收录申请或申请下架

## 适合谁

已经在用 DeepSeek Harness、想找插件扩展功能（主题、记忆、MCP、搜索、Office 等）的用户，以及想发布自己 DSH 插件的开发者。

## 怎么用

1. 在 DSH 中打开「插件 → 实验性插件 → 自定义插件市场」
2. 到「发现 → 添加索引源」，粘贴索引地址 https://dshopen.org/index.json
3. 在「发现」里搜索插件名并安装；也可以先在网站上浏览，再复制插件名到 DSH
4. 网站也提供通过 DSH 包名 dsh-open-market 一键配置的方式，安装前请先阅读其源码与说明

## 注意事项

- 浏览网站无需登录、免费；插件本身由第三方作者发布
- 站方明确说明“发布包检查不等于安装测试或代码审计”，插件会在你本机运行、读写文件或执行命令，安装前请看源码和权限说明，优先选带“已审查”标签、维护活跃的插件
- 部分插件会保存第三方账号 Cookie、调用模型产生费用，安装前看清说明
- 非 DeepSeek 官方项目
