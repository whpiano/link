## 这是什么

Bot-Hosting.net 是一个自 2021 年上线的托管平台，最初主打免费 Discord 机器人托管，现在也支持 Telegram 机器人、Node.js / Python 应用、网站和数据库。官网称有 50 万以上开发者使用。它提供免费套餐，也有付费套餐。

## 主要功能 / 要点

- 支持 Node.js、Python、Java、PHP、Go、Rust、C++、Lua、Bun 等运行环境
- 一键部署 MySQL、PostgreSQL、MongoDB、Redis 数据库，以及静态 / PHP 网站、Lavalink、Uptime Kuma
- 可从 GitHub（公开或私有仓库）、压缩包或社区模板部署
- 实时日志、CPU / 内存监控、容器 Shell，崩溃后自动重启，并有「Ask AI」帮你解读报错
- 免费 HTTPS 子域名（*.apps.bot-hosting.cloud），可绑定自有域名
- 提供 REST API、CLI、MCP 服务器和 OAuth

**免费套餐（官网所列）**：256 MB 内存、25% CPU、512 MB 存储、1 个部署，每小时备份、保留 24 小时，**需每 4 天在面板手动续期**。付费套餐从每月约 2.29 美元起。

## 适合谁

- 想让 Discord / Telegram 机器人 24 小时在线、又不想自己管服务器的人
- 跑小型脚本、爬虫、定时任务或学习部署的开发者

## 怎么用

1. 在官网注册并登录（Start free）。
2. 新建部署，选择运行环境，上传代码或连接 GitHub 仓库。
3. 在环境变量中填入 Token 等密钥（标记为 secret），启动即可。
4. 记得每 4 天登录面板续期一次免费实例。

## 注意事项

- 需注册登录；免费版资源很小，且忘记续期会停机，免费政策可能随时调整。
- 免费套餐页面写有「付费版无广告」，说明免费版可能有广告。
- 机器人 Token、数据库密码等托管在第三方平台，务必用环境变量的密钥功能保存，不要写死在代码里；重要数据自行备份。
