## 这是什么

flatkey.ai 是一个 AI 模型 API 聚合平台（Flatkey Inc.，官网标注地址位于美国圣何塞），用一个 API Key 调用 GPT、Claude、Gemini、DeepSeek、Qwen、GLM、Kimi、MiniMax、Grok、Seedance 等模型，覆盖文本、图片、视频、音频。注册页写明支持 160+ 官方模型，并提供 1000+ 按次计费的工具。

## 主要功能 / 要点

- 兼容 OpenAI 接口：替换 base URL 即可沿用现有 OpenAI SDK
- 统一预付费余额与发票，每次请求有 request ID 和用量记录
- 官网宣称平台侧失败不扣费、签署 99.5% SLA、多通道自动切换
- 官网显示部分模型相对官方价有折扣（如 GPT、DeepSeek 标"40% OFF"，Claude"20% OFF"），以实时价格页为准
- 子 Key 可设预算和模型白名单；提供 CLI，并支持接入 Codex、Claude Code
- 注册赠送免费测试额度，无需信用卡

## 适合谁

需要同时调用多家模型、希望一个账号统一计费的开发者和小团队，以及想低成本试用视频 / 图像生成模型的用户。

## 怎么用

通过链接注册（需邮箱验证码），进入控制台创建 API Key，把代码中的 base URL 改为 flatkey 提供的路由地址（官网示例为 router.flatkey.ai/v1），在请求里指定模型 ID 即可。

## 注意事项

- **这是带邀请码的推广链接**（url 含 aff=Os7K），注册后推荐人可能获得返利；介意可直接访问 flatkey.ai 注册
- 属第三方中转 / 聚合服务，"官方端点""零留存""折扣"等均为平台自述，无法独立核实；请求内容会经过第三方，敏感数据慎用
- 预付费余额存在平台跑路或政策变化风险，建议小额充值；免费额度可能随时调整或取消
- 使用中转服务可能不符合部分模型厂商的服务条款，需自行评估
