## 这是什么

「天才程序员中转站」（codexcli.club）是一家第三方 API 中转平台，官网称提供与官方完全兼容的 Claude 和 GPT 接口，用户只需替换 Base URL 和 Key 即可在 Claude Code、Codex CLI、Cherry Studio、OpenAI SDK 等工具中使用，按 token 实时计费、无月费。

## 主要功能 / 要点

- 按请求实际消耗计费，每次调用的模型、用量与费用可在账单记录中查看
- 可按人员/项目分别发 Key，并设置消费上限和到期时间
- 注册页可填写邀请码与优惠码
- 导航站原简介称每天有 50 张免费生图额度，原页面未能直接核实，以站内实际规则为准

## 适合谁

想低门槛试用 Claude Code、Codex 或 GPT 生图，又没有官方海外支付方式的个人开发者。

## 怎么用

打开链接注册账号，在控制台创建 API Key；按站内文档把客户端的 Base URL 改为中转站地址并填入 Key。建议先小额测试稳定性再充值。

## 注意事项

- 这是带邀请码的推广链接（url 含 aff=），注册后邀请人可能获得返利
- 第三方中转站非 OpenAI/Anthropic 官方：你的提示词与代码会经过其服务器，存在隐私泄露、跑路、模型被替换或“掺水”的风险，不要发送敏感数据
- 免费生图额度属于运营活动，可能随时调整或取消
- 使用中转服务可能违反上游模型厂商的服务条款，余额不建议大额充值
