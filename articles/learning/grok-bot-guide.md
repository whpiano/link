## 这是什么

这是“小声工作室”（作者莱因哈特）发布的中文长篇教程《Grok Bot 实战手册》2.0 版（2026-10-19），共 20 章、19 幅配图，约 36 分钟读完，可下载精排 PDF 和电商练习包。主题是把 xAI 的 Grok Bot 当作“数字员工”使用，并通过 Pi coding agent 接入 MiniMax 或 DeepSeek 等自有模型来分流额度。

## 主要功能 / 要点

- 从建立第一个 Bot、写岗位描述到第一份可追溯的科技简报
- 讲解安装 Pi、选择 MiniMax/DeepSeek、安全填写 API Key、手动添加模型
- 技能（Skill）、例行任务（Routine）、双 Bot 群聊交接与电商晨报练习
- 附 21 组可复制提示词、故障排查五层法和上线验收清单

## 适合谁

已订阅或打算使用 Grok Bot、想系统上手并控制额度成本的中文用户。

## 怎么用

直接在网页阅读，按“第一次使用 / 接自己的模型 / 让它重复做 / 协作与经营”四条路线选章节；需要离线时下载 PDF。

## 注意事项

- 教程免费阅读；但 Grok Bot 本身和外部模型 API 都需要各自的账号与付费
- 作者明确说明未在读者账户做端到端接入实测，“额度分流”不等于无限额度
- 按教程原则，API Key 只应填在产品的安全密钥入口，不要贴进普通聊天
- 产品价格、按钮名称、模型可用性变化快，以官方文档为准
