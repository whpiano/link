## 这是什么

这是 GitHub 用户 jangviktor-web 开源的 Agent Skill（约 4k Star，遵循 MulanPSL-2.0 协议，基于 huoyalong/nihaisha-skill 二次开发）。作者把已故经方中医倪海厦（1954–2012）的教学讲义、医案等资料整理“蒸馏”成可被 AI Agent 调用的技能，让 AI 以倪海厦的视角做六经辨证、讲解经方和药性。

## 主要功能 / 要点

- 内容涵盖伤寒论、金匮要略、黄帝内经、神农本草经、针灸等讲义资料
- 整理了六经辨证诊断公式、快速诊断流程图、脉舌速查等速查层
- 收录结构化医案与叙事医案，按疾病分类
- 还包含紫微斗数、易经六十四卦、风水等“天纪”内容
- 提供口语风格模块，让回答语气接近倪海厦本人
- 适配 Claude Code 等支持 Agent Skills 标准的工具，也上架了腾讯 SkillHub、IMA 等平台

## 适合谁

学习中医、研究经方的爱好者，以及想了解“把某位专家知识做成 Skill”这种做法的 AI 用户。

## 怎么用

1. 在支持 Agent Skills 的工具中安装：可 git clone 仓库后放到本地 skills 目录（如 Claude Code 的 skills 目录）
2. 也可在腾讯 SkillHub / IMA 的技能商店中获取
3. 对话中使用“倪海厦”“倪师”“经方思维”等激活词提问

## 注意事项

- 作者在免责声明中写明：内容仅供中医学习与研究，不替代专业医疗诊断，所有诊疗务必咨询执业医师
- AI 输出的方剂、剂量可能有误，切勿据此自行抓药、用药或停用现有治疗，尤其是附子等有毒药材
- 命理、风水等内容不具科学依据，请理性看待
- README 建议把一段安装指令直接发给 Agent 执行，安装第三方 Skill 前最好先查看其文件内容
