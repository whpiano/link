## 这是什么

digital-human-koubo（AI 数字人口播）是作者 Berryxia（andyhuo520）开源的一套 Agent Skill，MIT 协议，GitHub 约 1.8k Star。它的目标是「一张照片 + 一句话 → 一条成片的数字人口播视频」：由 AI 编程助手（如 Claude Code、Codex）按 SKILL.md 中的流程，自动完成写稿、生成对口型的数字人片段、声音处理、字幕和包装剪辑。

视频生成依赖第三方平台 Renoise（按积分计费），剪辑渲染用 Remotion。

## 主要功能 / 要点

- 用一张照片固定一个数字人形象（存放在 persona.json），可合成到直播间、教室等场景
- 脚本按 ≤15 秒分段生成对口型视频；先报价（片段数、秒数、积分）并等用户确认后才生成
- 用 whisper 回听校对、抽帧检查画面问题，自动重拍问题片段
- 声音统一处理（频谱匹配、去齿音、统一混响、响度标准化）
- 5 种剪辑风格（财经科普、带货口播、发布会解读、教程、多主播多语言）和 48 个包装组件
- 自动生成封面作为首帧，支持多语言

## 适合谁

- 做短视频、知识口播、带货内容的创作者
- 会使用 Claude Code / Codex 等 AI 编程助手、能在本地装 ffmpeg、Python、Node 的用户

## 怎么用

按 README：克隆仓库，把 skills 目录下的两个技能复制到你所用 Agent 的技能目录；在 Renoise 注册账号并把它的 MCP 服务接入 Agent；本地安装 ffmpeg、Python、Node.js、whisper.cpp 等工具。之后用自然语言对 Agent 下指令即可，例如「用我的数字人 Skill 做一条 30 秒带货视频」。具体命令以仓库 README 为准。

## 注意事项

- 代码免费开源，但视频生成要在 Renoise 消耗付费积分（README 示例：27 秒视频约 482 积分）；Remotion 对 3 人以上公司需商业授权。
- 只能使用自己或已获明确授权的人像与声音，不要冒充真人；作者要求成片标注「AI 数字人演绎」。
- 照片和脚本会上传到第三方生成平台，注意隐私。
- 安装步骤涉及在本机执行脚本和安装软件，执行前请自行阅读代码。
