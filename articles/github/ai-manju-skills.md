# AI 漫剧 Skills（ai-manju-skills）

- **原链接：** <https://github.com/zhanghao123vip/ai-manju-skills>
- **分类：** GitHub 开源项目
- **标签：** `Skill` `AI漫剧` `提示词模板` `短剧`
- **收录日期：** 2026-11-17

## 这是什么

一套 21 个题材的 AI 漫剧全流程模板，每个模板就是一个 `SKILL.md` 文件，无需安装依赖。发一句故事点子，即可得到企划案、资产图提示词、分集剧本、分镜图与视频提示词、发布文案。MIT 许可证。

## 主要功能 / 要点

- 21 个题材：幻想（玄幻修仙、西幻、星际机甲等）、古代（宫斗、宅斗、武侠等）、现代（都市逆袭、总裁甜宠、娱乐圈等）、类型片（悬疑刑侦、民俗怪谈）
- 五类输出：企划案、资产库、分集剧本、分集导演手册、发布包
- 默认 30 集、每集约 4 分钟、9:16 竖屏，可自定义
- 分批输出，回复“继续”写下一批；支持“改：……”局部修改

## 适合谁

想用 AI 批量做竖屏漫剧/短剧的创作者，以及用 Claude Code、WorkBuddy、DeepSeek 等工具的用户。

## 怎么用

- 聊天工具：复制对应题材 `SKILL.md` 全文粘贴到新对话，待回复“模板已就绪”后发故事点子；一部剧一个对话、一个模板。
- Claude Code：把题材文件夹复制到 `~/.claude/skills/`。
- WorkBuddy：导入 Skill 或整段粘贴。

## 注意事项

- 作者说明多数题材尚未逐一实测，效果因题材而异。
- 提示词里的 `{{Mixed N}}` 是参考图写法，换视频工具需调整。
- 发布前需按平台规则合规并标注 AI 生成；版权与合规责任自负。
- 使用前建议先阅读 SKILL.md 内容再粘贴到工具中。
