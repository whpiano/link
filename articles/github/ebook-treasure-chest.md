- **收录日期：** 2026-11-05

## 这是什么

「电子书下载宝库」是 GitHub 用户 jbiaojerry 维护的仓库（约 2.3 万星）。它把从各电子书网站收集来的下载链接按标签整理成 Markdown 列表，README 称覆盖帆书（原樊登读书）、微信读书、京东读书、喜马拉雅等读书 App 上的大部分书目。

## 主要功能 / 要点

- 每本书一般提供 epub、mobi、azw3 三种格式链接
- 按“文学、历史、科普、管理、心理”等数百个标签分页，标签后标有数量
- 提供 GitHub Pages 在线搜索页，支持书名/作者/分类多关键词实时搜索
- 仓库本身只放索引，书文件托管在外部链接上

## 适合谁

想快速找某本中文书电子版、习惯用 Kindle 或其他阅读器的读者。

## 怎么用

打开仓库 README，点击感兴趣的分类标签进入列表；或直接访问 README 里给出的 GitHub Pages 搜索页，输入书名搜索，再点对应格式的下载链接。

## 注意事项

- 无需登录即可浏览，不收费（作者附有赞赏码，自愿）
- 这类合集里的书大多受版权保护，下载与传播可能侵犯著作权，请自行判断并优先支持正版
- 下载链接指向第三方网盘或站点，可能失效、跳广告，或被替换成恶意文件；下载后建议杀毒，不要运行 .exe 等可执行文件
