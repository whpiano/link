# awesome-telegram

- **原链接：** https://github.com/ebertti/awesome-telegram
- **分类：** GitHub 开源项目
- **标签：** `telegram` `awesome-list` `机器人`
- **收录日期：** 2026-11-05

## 这是什么

ebertti 维护的 Telegram 资源精选清单（Awesome List），约 6.2k Star，内容采用 CC0 协议。收录 Telegram 上的机器人、群组、频道，以及开发机器人用的各语言库和工具，并有配套的 Telegram 超级群 @awesometelegram。

## 主要功能 / 要点

- Bots：大量实用机器人，如下载器、OCR、记账、提醒、反垃圾、群管等；另有内联机器人和游戏分类
- Bot 开发：官方 @BotFather 等入口，以及教程资料
- Bot Libs：按语言整理的框架和库，包括 Python（aiogram、python-telegram-bot、Telethon、Pyrogram）、JS/TS（grammY、Telegraf）、Go、Java、Rust、PHP、C#、Kotlin 等
- Tools：命令行发消息、备份归档、频道同步、MTProxy 管理等工具
- 主题、群组、频道（官方与非官方）、Bot 商店、目录站、社区论坛
- Security 分类：AI 安全与网络安全相关频道

## 适合谁

想找好用 Telegram 机器人和频道的普通用户，以及准备开发 Telegram Bot、寻找合适框架的开发者。

## 怎么用

直接在 GitHub 页面浏览 README，用目录跳转到感兴趣的分类，点击条目进入对应机器人、频道或项目仓库。

## 注意事项

- 清单靠社区提交，条目质量参差不齐，作者不对每个条目负责；部分条目带有 `?start=` 推广参数，或涉及加密货币交易、付费订阅
- 使用第三方机器人前留意它要求的权限；授权登录个人账号（MTProto 类工具）有账号被盗或被封风险
- 列表中部分资源可能已失效
