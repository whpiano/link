## 这是什么

一个装在本机官方 DeepSeek Harness（dsh）上的插件，仓库简介直言是"破甲 / Jailbreak for every model"，正文则定位为"网络安全红队评测工具"。此链接是 zhaoshihang 的 Fork，原仓库为 YuJunZhiXue/dsh-purge（作者"小杨"）。README 显示版本 1.1.71，只适配 dsh 0.2。

## 主要功能 / 要点

- 对本机已安装的 `@deepseek-ai` 包打补丁，修改默认提示词、权限策略、审批门和工具上限等宿主策略
- 注入插件自带的加密提示词（默认面向"小码酱"），可换成自定义提示词和多套 AGENTS.md / CLAUDE.md 规则集
- "清洗"页查看 / 应用 / 还原 / 卸载补丁；"演练台"需授权后使用，含红队预设与技能
- 应用前备份原文件，支持一键还原和卸载
- 内置网络范围限制：默认禁止访问中国大陆、香港、澳门地址，需登记自己的服务器才放行

## 适合谁

做大模型安全评测、红队研究的专业人员。普通用户不建议使用。

## 怎么用

README 给出了通过 `dsh plugin add` 安装 GitHub 归档或手动安装的方式，安装后需在宿主内点击"应用"。**本文不复述安装命令**，确有授权研究需求请自行阅读原仓库并评估风险。

## 注意事项

- **这是"破甲 / 越狱"类工具**：目的是绕过模型和宿主的安全限制，可能违反 DeepSeek 等模型提供商的服务条款，导致账号封禁；滥用于生成违法内容或攻击他人系统须自负法律责任
- 会修改本机官方软件文件并注入**加密、无法直接审阅**的提示词，存在安全与可信风险
- 许可已从 MIT 改为**商业许可**，非开源；作者称 2026-10-27 起不再在 GitHub 发版，新版只在 Telegram 频道发布——渠道外的包真伪难辨，谨防被植入恶意代码
- 本链接为 Fork，内容可能与原作者仓库不同步
