## 这是什么

Erosion-CN 是上游项目 jailbreakdotparty/Erosion（基于 worse_query）的简体中文分支，是一个 iOS / iPadOS 系统配置与 MobileGestalt 研究工具箱，GPLv3 开源。

## 主要功能 / 要点

- 100% 简体中文界面
- 修复重启后修改失效、Plist 编辑导致相机黑屏等问题
- 写入前差异预览、写后读回校验与自动回滚、备份 SHA-256 校验
- Apple 智能相关开关、应用存档备份还原、容器缓存清理、文件浏览器等
- 支持 iOS/iPadOS 27.0–27.2、27.3 beta 1（完整）及 26.x（部分）

## 适合谁

有 iOS 系统研究、侧载经验、愿意折腾自己设备的进阶用户。

## 怎么用

按 README 说明：从 Releases 下载 ipa，用 SideStore / AltStore / Feather 等需保留 App Group 的自签工具安装，详见仓库 USAGE_GUIDE.md 与 RESTORE_CHA.md。

## 注意事项

- 修改系统底层配置有变砖、数据丢失风险，务必先用电脑完整备份，仅在自己的设备上使用
- 需要自签安装 ipa，请仅从官方 Releases 下载并自行审查来源
- 可能影响售后、基带/eSIM 等，作者声明不承担责任
- 本文依据 README 整理，未实际安装测试
