# Aerial：给国产电视换一块干净桌面

- **原链接：** <https://github.com/pengchujin/aerial-tv>
- **分类：** GitHub 开源项目
- **标签：** `Android TV` `电视桌面` `去广告` `屏保` `开源`
- **收录日期：** 2026-11-05

## 这是什么

Aerial 是 pengchujin 做的开源 Android TV 桌面（启动器），界面参照 Apple TV：没有广告、没有推荐流，只有你的 App、壁纸和航拍屏保。主要面向小米、TCL、创维、索尼、海信等国产电视，也能装在电视盒子和投影仪上。MIT 许可，官网 <https://aerial.qust.me>。

## 主要功能 / 要点

- **干净首页**：常用 App 放在底部玻璃底板，往下是全部 App，连小米「应用中心」「米家」这类隐藏的系统 App 也能找到。
- **整理**：长按 OK 键可移动、建文件夹、隐藏、卸载，或设成「开机时打开」；HDMI 信号源可固定到主屏并换成 Apple TV、PS、Switch 等图标。
- **用手机整理**：扫电视上的二维码，在手机上拖动排序、改名、换图标。
- **控制中心**：信号源、网络、音量、亮度、个性化集中在右上角。
- **屏保与壁纸**：Apple TV 的 114 段航拍影片（支持时播 4K / 杜比视界），也可用照片、时钟、必应每日图或手机传的视频。
- **个性化**：每排 4/5/6 个 App、单双排、时钟样式、焦点样式、按键声等都能改。
- **接管桌面**：国产电视大多只认自家桌面，Aerial 用无障碍服务在原桌面出现时切回（作者称只看前台窗口、不读屏幕内容），并用通知监听在被清理后拉起（称不读通知）。
- **Aerial Lite**：给 Android 4.0–4.4 老电视的测试版。
- README 附有很长的机型兼容表（✅/⚠️/❌），装前建议先查自己的型号。

## 适合谁

- 受不了国产电视开机满屏推荐、会员角标的人。
- 主要用电视看 HDMI 设备（Apple TV、游戏机）或少数几个 App、想要简洁桌面的人。
- 愿意动手打开 ADB 调试的用户。

## 怎么用

1. 在电视上打开 ADB 调试（各品牌入口不同，README 有对照表；Android 11+ 只有无线调试的要先配对）。
2. 用电脑上的 adb 安装 APK 并授予几项权限，或用官方的一行安装脚本；也可以只用 U 盘装 APK，但这样接管主页键、开机进入的效果有限。
3. 按主页键选 Aerial 为默认桌面；国产电视按提示开启「桌面守护」（无障碍）和通知使用权。
4. 想还原：清除默认桌面设置或运行官方的 restore 脚本，可选择同时卸载。原来的桌面、会员、小爱、账号都还在。

## 注意事项

- **免费开源**，不需要登录，不需要 root；但需要打开 ADB 调试并授予 `WRITE_SECURE_SETTINGS`、无障碍、通知监听、悬浮窗等较高权限，请只从官方 Releases 或官网下载。
- 官方提供 `curl ... | bash` 一行安装方式，会直接在你电脑上运行远程脚本，运行前最好先打开脚本看一眼。
- README 里有给 AI Agent 的安装提示词，让 Agent 在你电脑上执行命令；交给 Agent 前要清楚它会改动电视设置。
- `KEEP_ADB=1` 会让 ADB 保持常开，方便升级，但局域网内其他设备也可能连上电视的 ADB；家庭网络不可信时慎用。
- 部分机型接管不完整或不可用（如部分雷鸟、创维 Android 13、坚果 S621 等）；开机广告是固件播的，去不掉。
- 不支持 LG webOS、三星 Tizen、华为鸿蒙智慧屏。
- 航拍影片版权归 Apple，由 Apple 服务器直接播放；项目与 Apple、小米、TCL 等无关。
